What it is

A research tool, not a SaaS.

Notesci was built for one person — the researcher running it — to ingest papers, ask questions across their own corpus, generate drafts with reviewer feedback, and trace every claim back to a source. There is no team surface, no sharing, no billing. One person, one workspace, one machine.

It speaks to multiple LLM providers (Anthropic, OpenAI, Google, DeepSeek) through a single chokepoint, so you're never locked into a vendor. It hosts MCP servers for tools you bring yourself. It stores everything in Postgres + pgvector that you control. And it never sends your private notes to a third party you didn't explicitly configure.

This is a fully open-source project. The hosted instance has been retired, and the project now exists as source code you run yourself.

What's inside

The pieces that make it work.

Multi-provider LLMs

Anthropic, OpenAI, Google, DeepSeek — pick per session, per draft stage, or per reviewer. One chokepoint, zero vendor lock-in.

MCP tools, curated

A server-curated catalog of MCP integrations — one-click install, no JSON to author. Bring your own servers too.

Citations & graph view

Every claim is grounded in a source. Four graph lenses — Map, Citations, Concepts, Reasoning — turn your corpus into something you can navigate.

Drafting pipeline

Pre-flight interview → gather → draft → polish → review → iterate until every reviewer signs off. Per-stage model overrides for when you want a different brain on each turn.

Open source

Built in public, shipped as source.

Notesci is maintained as a fully open-source project. If you care about trust, reproducibility, and owning your research environment, the project assumptions and toolchain choices are visible in source control.

We intentionally keep the stack minimal and composable: you can replace providers, add MCP servers, and pin versions yourself. Pull requests and issue discussions are the normal channel for roadmap and fixes.

This means no product lock-in, no paid-hosted dependency in the core pipeline, and no hidden telemetry path in the codebase.

Get it running

Self-host in three steps.

notesci ships as a FastAPI backend (Python + LangGraph + Postgres/pgvector) and a Vite + React frontend. Docker Compose handles both. You'll need a host with at least 2 GB of RAM and your own API keys for whichever LLM providers you want to use.

  1. Clone the repo

    git clone https://github.com/psypeal/notesci and copy .env.example to .env.

  2. Add your API keys

    Drop in keys for any of Anthropic, OpenAI, Google, or DeepSeek. Provider-locked features gracefully fall back when a key is missing.

  3. Boot it

    docker compose up -d brings up Postgres, the backend, and the frontend behind nginx. Open localhost and you're in.
